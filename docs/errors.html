Errors

All client-specific errors extend the base RMPError class, which itself extends Error. Use instanceof to distinguish between error types. 

import {
  RMPError,
  HttpError,
  ParsingError,
  RateLimitError,
  RetryError,
  RMPAPIError,
  ConfigurationError,
} from "ratemyprofessors-client";

Catching Errors #

Use instanceof to narrow the error type and access type-specific properties:

try {
  const prof = await client.getProfessor(id);
} catch (e) {
  if (e instanceof ParsingError) {
    // Professor not found or response shape changed
    console.error("Not found:", e.message);
  } else if (e instanceof HttpError) {
    // Server returned a non-2xx status
    console.error("HTTP", e.status_code, e.url);
  } else if (e instanceof RetryError) {
    // All retries exhausted
    console.error("Gave up after retries:", e.last_error.message);
  } else if (e instanceof RateLimitError) {
    // Local rate limiter blocked the request
    console.error("Too many requests:", e.message);
  } else if (e instanceof RMPAPIError) {
    // GraphQL API returned errors
    console.error("API error:", e.message, e.details);
  } else {
    throw e; // Unknown error
  }
}

RMPError #

Base class for all client errors. You can catch this to handle any client-specific error generically.

PropertyTypeDescription
messagestringHuman-readable error message
name"RMPError"Error name

HttpError #

Thrown when the server returns a non-2xx HTTP status code (e.g. 404, 500).

PropertyTypeDescription
status_codenumberHTTP status code (e.g. 404, 500)
urlstringThe URL that was requested
bodystring | undefinedResponse body text (when available)

When thrown: Any time a network request returns a non-2xx response.

ParsingError #

Thrown when the response can't be parsed into the expected shape, or when the requested entity doesn't exist.

PropertyTypeDescription
messagestringWhat went wrong (e.g. "Teacher not found")

When thrown:

  • getProfessor(id) when the professor doesn't exist
  • getSchool(id) when the school doesn't exist
  • Ratings page fetches when the GraphQL response is missing data.node

RateLimitError #

Thrown when the client's local token-bucket rate limiter blocks a request. By default the client waits for a token to become available; this error is thrown when using non-blocking mode.

PropertyTypeDescription
messagestringDefaults to "Local rate limit exceeded"

When thrown: When the configured rate_limit_per_minute would be exceeded.

RetryError #

Thrown when all retry attempts are exhausted (e.g. repeated 5xx responses or network failures).

PropertyTypeDescription
last_errorErrorThe last error that caused the final failure

When thrown: After max_retries failed attempts on any request.

RMPAPIError #

Thrown when the RMP GraphQL API returns an errors array in the response body (the HTTP status may still be 200).

PropertyTypeDescription
messagestringCombined error message
detailsunknownRaw error payload from the API

When thrown: When the GraphQL response includes "errors": [...].

ConfigurationError #

Thrown when client configuration is invalid.

PropertyTypeDescription
messagestringWhat's wrong with the configuration

When thrown: During client construction if a required config value is missing or invalid.
