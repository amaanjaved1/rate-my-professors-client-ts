Extras

Optional helpers for data pipelines — deduplication, course code normalization, and sentiment analysis. Import from the extras subpath: 

import {
  normalizeComment,
  isValidComment,
  cleanCourseLabel,
  buildCourseMapping,
  analyzeSentiment,
} from "ratemyprofessors-client/extras";

Deduplication #

normalizeComment

normalizeComment(text: string): string

Normalizes text for comparison by trimming, lowercasing, and collapsing whitespace. Useful for detecting duplicate reviews. 

const a = normalizeComment("  Great  Professor!  ");
const b = normalizeComment("great professor!");
console.log(a === b); // true

isValidComment

isValidComment(text: string, minLen?: number): boolean

Returns whether a comment is non-empty and at least minLen characters long (default 10). Use to filter out low-quality or blank reviews.

ParameterTypeDefaultDescription
textstring—Comment text
minLennumber10Minimum character length
isValidComment("Good");       // false (too short)
isValidComment("Great class, learned a lot"); // true

Course Codes #

cleanCourseLabel

cleanCourseLabel(raw: string): string

Cleans a scraped course label by removing parenthesized counts and normalizing whitespace. 

cleanCourseLabel("CS 101 (42)"); // "CS 101"

buildCourseMapping

buildCourseMapping(scrapedLabels: Iterable<string>, validCourses: Iterable<string>): Map<string, Set<string> | null>

Maps scraped course labels to valid course codes. Returns a Map where each key is a cleaned label and the value is either a Set of matching course codes or null when the label is ambiguous or unknown.

ParameterTypeDescription
scrapedLabelsIterable<string>Labels scraped from RMP (e.g. from rating course_raw)
validCoursesIterable<string>Known valid course codes from your institution
const mapping = buildCourseMapping(
  ["CS 101 (42)", "MATH200"],
  ["CS101", "CS102", "MATH200"]
);
// Map { "CS 101" => Set { "CS101" }, "MATH200" => Set { "MATH200" } }

Sentiment #

analyzeSentiment

analyzeSentiment(text: string, getPolarity: (text: string) => number): SentimentResult

Computes a sentiment label from a polarity score. You provide a polarity function (e.g. from a sentiment library) that returns a number in [-1, 1].

ParameterTypeDescription
textstringThe text to analyze
getPolarity(text: string) => numberFunction returning polarity in [-1, 1]

Returns: SentimentResult

FieldTypeDescription
scorenumberRaw polarity score
labelSentimentLabelOne of: "very positive", "positive", "neutral", "negative", "very negative"
const result = analyzeSentiment("Amazing professor!", myPolarityFn);
console.log(result.label); // "very positive"
console.log(result.score); // 0.85
